# Resume Directory

Please place your resume file in this folder.
Supported formats:
- PDF: e.g. `resume.pdf`
- Word: e.g. `resume.docx`
- Text / Markdown: e.g. `resume.txt` or `resume.md`

The automated scout engine will automatically detect and parse this file to:
1. Extract your core skills (e.g. Python, SQL, Tableau, PowerBI, Excel, Pandas, Machine Learning, etc.)
2. Match them against newly posted entry-level jobs
3. Generate tailored cover letters and customized application responses
